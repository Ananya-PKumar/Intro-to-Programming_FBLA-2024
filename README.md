# GPA Calculator for FBLA 2023-2024
By Ananya Premkumar

Hello! This is a GPA Calculator that I built during the 2023-2024 FBLA Competition, that (out of 86 national qualifying teams) placed Top 12 at the FBLA National Leadership Conference. 

This program is heavily Java based; however, I incorporated SQLite to locally store registered users into a database I made on the VSCode IDE.

To ensure smooth functionality of this GPA Calculator, please download the NetBeans IDE, VSCode IDE (to make the SQLite database connection), ensure you have Java downloaded, and then download the respective files here and upload them into NetBeans.

Please note that the GUI code is autogenerated, due to using NetBeans' GUI Design feature.

Instructions are provided within the "Instructions.java" file.
